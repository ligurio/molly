Module molly.thread_coroutine

Module with implementation of threads based on coroutines.

References

  • "Programming in Lua, Coroutines", Roberto Ierusalimschy, http://www.lua.org/pil/9.html
  • "Coroutines in Lua" - Ana L´ucia de Moura, Noemi Rodriguez, Roberto Ierusalimschy, https://www.lua.org/doc/jucs04.pdf

The module provides a thread object (new, create, cancel, join and yield methods) and a scheduler that runs registered threads. Thread synchronization primitives are exported by molly.thread.
